# QuiroScanner App

Herramienta digital para análisis y evaluación, construida con React y TypeScript.

## 🚀 Demo
http://tao.octaviotrs.com

## ✨ Características
- Interfaz moderna y responsive
- Componentes tipados con TypeScript
- Experiencia de usuario clara y enfocada
- Arquitectura modular y reutilizable

## 🛠️ Tech Stack
- **Frontend:** React + TypeScript
- **Estilos:** CSS / Tailwind
- **Deploy:** Vercel (o la plataforma que uses)

## 📦 Cómo correrlo localmente

```bash
git clone https://github.com/budasun/quiroscannerapp.git
cd quiroscannerapp
npm install
npm run dev
